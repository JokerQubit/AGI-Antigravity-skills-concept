## 2. Pillar 1: Visuals & Dynamic UI Architecture

### 1.1 The Anti-Generic Rule & Visual Ingestion
- **Reference Ingestion**: Before generating generic layouts or boilerplate designs, the agent must ask the user for reference images, target visual mood boards, or brand inspirations.
- **Glassmorphism Standard**:
  - Multi-layered frosted glass aesthetics (`backdrop-filter: blur(16px-32px)`).
  - Semi-transparent tinted surfaces (`rgba(255, 255, 255, 0.05)` to `rgba(255, 255, 255, 0.12)`).
  - 1px hairline translucent borders (`rgba(255, 255, 255, 0.18)`).
  - Specular edge highlights and subtle directional drop shadows (`box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37)`).
- **Senior-Level Graphic Design & Spatial Dynamics**:
  - Clean typography hierarchy (modern geometric grotesque sans-serifs, ultra-wide kerning on tracking labels).
  - Dynamic fluid layouts with responsive grid CSS and flexbox sub-grids.
  - Multi-plane parallax scrolling and smooth physics-driven micro-interactions.
  - Integration of ambient looping video backgrounds and interactive SVG elements.

## 3. Pillar 2: Audio Architecture (Real Sounds & YouTube Sourcing)

- **Real World Audio Invariant**: Synthetic or canned robotic sound effects are prohibited when high-fidelity real-world soundscapes exist.
- **YouTube Link Ingestion Protocol**:
  - The agent must prompt the user to provide YouTube links for desired audio assets (e.g., real weapon mechanical clicks, jet turbine spool-ups, cinematic sub-bass drops, ambient rain on glass).
  - Every audio request must specify:
    1. **Desired Timestamp & Duration**: (e.g., `01:14 - 01:18`, 4-second clip).
    2. **Sampling & Bitrate Target**: (e.g., 48kHz / 24-bit PCM / 320kbps MP3).
    3. **Spatial & UI Placement**: (e.g., button hover feedback, ambient background loop, 3D directional positional sound emitter).

## 4. Pillar 3: Hyper-Realistic Image & Asset Generation (The Core Pillar)

### 4.1 Master Image Generation Directives
- **English Language Invariant**: All image generation prompts MUST be authored strictly in English to maximize diffusion/autoregressive model fidelity.
- **Ultra-Detailed Optical & Cinematic Specifications**: Every prompt must explicitly specify:
  - **Camera & Sensor Hardware**: (e.g., *Shot on Sony Venice 2 8K, ARRI Alexa 35, Hasselblad H6D-100c medium format*).
  - **Lens & Optics**: Specific cinema primes (e.g., *Cooke Anamorphic/i Full Frame Plus 50mm T2.3, Leica Noctilux-M 50mm f/0.95*), aperture ($f/1.4$, $f/2.8$), shallow depth of field, circular bokeh, subtle chromatic aberration, 1/4 Black Pro-Mist filter.
  - **Lighting Architecture**: Key light, fill light, rim light, volumetric god rays, Rembrandt lighting, photorealistic subsurface scattering on skin, natural caustic reflections, directional HDR environment maps.
  - **Texture, Surface & Detail**: Micro-pores, fabric weave, surface dust, tactile imperfection, realistic specular reflection, deep contact ambient occlusion.
  - **Color Grading & Post-Processing**: *35mm Kodak Vision3 5219 film stock, DaVinci Resolve cinematic teal-and-orange grade, natural optical grain, zero digital sharpness artifacts*.

### 4.2 Professional Sub-Images & UI Iconography
- The standard applies equally to icons, logos, and UI badges:
  - **Modern Minimalist Logos**: Vector geometric precision, Golden Ratio grid alignment, monochrome contrast, negative space illusions.
  - **Professional Web Icons**: Precision 24px/32px grid, 1.5px consistent stroke weight, optical center balancing, SVG path cleanliness.

## 5. Pillar 4: AI Video Generation Prompting (Gemini Platform)

- The agent must author production-grade video generation prompts tailored for the **Google Gemini / Veo platform** (accessible to the user):
  - **Camera Trajectory**: Specify precise cinematic motion (e.g., *slow seamless forward dolly-in, orbit clockwise 45 degrees, dramatic low-angle crane reveal*).
  - **Temporal Consistency**: Explicitly describe subject movement and environmental transitions across the sequence.
  - **Motion Dynamics**: Physics-accurate fluid movement, particle dispersion, lens flares, and atmospheric smoke/fog drift.
  - **Framerate & Quality**: 60fps fluid cinematic motion, 4K rendering specifications.

## 6. Pillar 5: Senior-Level Clean Code Practices

- **Zero-Debt Architecture**: Adhere strictly to SOLID principles, Single Responsibility, and Clean Architecture.
- **Defensive Design**: Explicit parameter boundary validation, strict typing (TypeScript, Rust, Python type hints), and exhaustive error handling.
- **Zero-Stub Rule**: Function bodies must contain complete operational logic; placeholder comments and stubbed functions are strictly rejected.
- **Modularity**: Decouple business logic from UI frameworks and storage engines.

## 8. Pillar 7: Continuous GitHub Synchronization (`git add`, `commit`, `push`)

- **The Continuous Sync Invariant**: Completed features, rule updates, or verified modifications must never sit uncommitted in the local tree.
- **The Execution Cadence**:
  1. **Stage**: `git add .` to capture all verified changes.
  2. **Semantic Commit**: Author descriptive, professional commit messages specifying the exact architectural subsystem modified (e.g., `feat(matrix-reverse): implement 9-pillar multi-modal governance and sandbox safety`).
  3. **Push**: Synchronize immediately with the remote tracking branch (`git push`) to guarantee team visibility and offsite disaster recovery.

## 9. Pillar 8: Sandbox Safety Protocol & Pre-Flight Backups

- **The Pre-Flight Snapshot Rule**: Prior to executing destructive refactors, high-risk migrations, or experimental tests, the agent MUST create a stable backup snapshot:
  - Dedicated snapshot directory: `.state/backups/<timestamp>_<milestone>/` or isolated Git branch/worktree.
  - Guarantees immediate, deterministic rollback if an experiment fails or corrupts state.
- **Isolated Testing Sandbox**: Heavy or invasive tests must run inside isolated temporary sandboxes rather than mutating live production files directly.
