# SKILL: Zero-Trust Multi-Agent Knowledge Synthesis & Formal Verification Protocol

## I. Evidence-Grounded Model Aggregation
Synthesis aggregates N independent domain implementations into a unified formal specification:
- Extracts mathematical models, invariant assertions, state transition tables, and edge-case behaviors.
- Construct a Conflict Resolution Matrix ($M_{\text{conflict}}$) highlighting contradictions between target implementations.

## II. Dynamic Epistemic Grill-Me (Socratic Verification)
Eliminates arbitrary question counts (e.g. 50 questions). Replaces them with Epistemic Confidence Bounds ($DEC$):
- Socratic grilling continues dynamically until all open epistemic uncertainties drop below the target bound ($\text{Uncertainty}(K) < 0.01$).
- Formally validates types, numerical stability, overflow conditions, state invariant preservation, and concurrency safety.

## III. Automated Formal & Metamorphic Verification
- Synthesized specifications must include executable metamorphic properties (e.g. scale invariance, temporal shift invariance, regime invariance).
- Scientific Review requires automated test execution against candidate implementations or formal solver verification (e.g. Z3 / SMT solvers) before sign-off.
