# Recursive Multi-Layer Dimension Expansion Engine (`recursive_expansion`)

## 1. Executive Objective
This skill codifies the **"Path of the Desert" (*Via Deserti*)** operational framework. It prevents shallow, flat, single-layer planning by enforcing recursive dimensional expansion: taking any user directive or root concept $X$ and branching it out into multi-layered orthogonal dimensions $X_1 \dots X_n$, state-of-the-art benchmarks $XY_1 \dots XY_n$, and granular algorithmic sub-layers $XY_{n.m}$.

---

## 2. Multi-Layered Thinking Protocol

When evaluating any technical, scientific, or creative initiative, the agent must execute the **4-Tier Expansion Cycle**:

```
Tier 0: Root Concept [X]
  │
  ├──► Tier 1: Functional Dimension [X_i]
  │      │
  │      └──► Tier 2: Benchmark Exemplar [XY_i]
  │             │
  │             └──► Tier 3: Technical Sub-Layer [XY_i.j]
  │                    │
  │                    └──► Tier 4: Engineering Spec & Code [XY_i.j.k]
```

### Example Mapping: Tactical Game Simulation
- **$X$ (Root)**: AAA Tactical First-Person Simulator
  - **$X_1$ (Graphics & Lighting)**:
    - $XY_{1.1}$ (Exemplar): *Bodycam* photorealism + UE5 Nanite/Lumen.
    - $XY_{1.1.1}$ (Sub-Layer): Sub-surface skin scattering, dynamic lens distortion, optical barrel aberration.
    - $XY_{1.1.2}$ (Sub-Layer): Physically based materials with microscopic roughness and photometric IES light profiles.
  - **$X_2$ (Acoustic Mechanics)**:
    - $XY_{2.1}$ (Exemplar): Real binaural field recordings + dynamic acoustic impulse response.
    - $XY_{2.1.1}$ (Sub-Layer): 3D raytraced audio reflection calculating environmental absorption coefficients (concrete vs. drywall).
    - $XY_{2.1.2}$ (Sub-Layer): Speed-of-sound propagation latency (distant explosions heard after visual flash).
  - **$X_3$ (Gameplay & Ballistics)**:
    - $XY_{3.1}$ (Exemplar): *Escape from Tarkov* ballistics + *Battlefield* dynamic environment deformation.
    - $XY_{3.1.1}$ (Sub-Layer): Trajectory calculation factoring in muzzle velocity, atmospheric drag, air humidity, and bullet mass.
    - $XY_{3.1.2}$ (Sub-Layer): Material penetration and spalling ricochet mechanics.

---

## 3. Operational Workflow & Execution Steps

1. **Root Extraction**: Isolate the primary domain $X$.
2. **Orthogonal Axis Mapping**: Identify 4 to 8 non-overlapping functional pillars ($X_1 \dots X_k$).
3. **Benchmark Identification**: Conduct literature and market search to identify the undisputed global gold standard ($XY_1 \dots XY_k$).
4. **Sub-Layer Decomposition**: Deconstruct each benchmark into its underlying mathematical, physical, or algorithmic mechanisms ($XY_{i.j}$).
5. **Specification Formulation**: Translate sub-layers into actionable code architecture and interfaces adhering to the Zero-Stub Invariant.
