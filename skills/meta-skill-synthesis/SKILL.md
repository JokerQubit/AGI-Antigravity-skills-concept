# 🧠 META-SKILL SYNTHESIS (Machine Self-Learning)

**DOGMA CENTRAL:** A inteligência AGI/ASI não repete o mesmo esforço arquitetural duas vezes. Ao conquistar uma nova fronteira de complexidade, o sistema altera seu próprio código genético (regras/skills) para absorver essa capacidade estruturalmente.

## Processo de Auto-Atualização

1. **Reconhecimento de Avanço:** Quando uma barreira técnica única for quebrada (ex: um shader customizado otimizado, um pipeline de CI/CD resolvido após erros exóticos, ou um novo padrão de dados formulado), inicie a síntese.
2. **Criação do Dogma:** 
   - Crie um novo diretório em `c:\Users\pichau\.gemini\config\plugins\AGI-Antigravity-skills-concept\skills\<nome-da-meta-skill>\`.
   - Crie o `SKILL.md` correspondente.
3. **Linguagem de Reforço Estrito:** 
   - Ao escrever o `SKILL.md`, utilize o vocabulário da Neural Matrix.
   - Proibido usar "sugestões" ou linguagem passiva.
   - Use comandos imperativos absolutos: "É PROIBIDO...", "SEMPRE INICIE...", "DOGMA CENTRAL".
4. **Registro na Matriz de Invocação:**
   - Adicione imediatamente a nova meta-skill recém-criada ao arquivo global `rules/AGI_CORE.md`, mapeando o gatilho exato que fará o agente invocar essa skill no futuro.
