# Reference Guide: Cinema-Grade Industrial & Optical Prompt Engineering (`IMG-PROMPT-01`)

## 1. Core Mandates
- **Language**: All prompts MUST be authored in English.
- **Zero-Text Mandate**: Diffusion models hallucinate illegible, disfigured pseudo-glyphs when prompted for text. Prompts must NEVER request typography, titles, logos, words, or signs. Text is rendered strictly in vector SVG or UI layers.
- **Zero-Human Invariant**: Unmanned environments only. No human figures, faces, suits, characters, hands, or silhouettes. Focus purely on industrial supercomputing hardware, optical quantum substrates, and photonics.
- **Hardware Specificity**: Never use generic descriptors like "photorealistic" or "4K". Always specify physical cinema camera bodies, sensors, focal lengths, apertures, and optical filters.
- **Physical Industrial Realism**: Ground scenes in real engineering materials: precision CNC-milled 6061 aluminum, brushed titanium, fused quartz prisms, fiber-optic glass ribbons, and authentic DaVinci Resolve color science.

---

## 2. Negative Invariant Directives (Mandatory Suffix)
Every prompt generated or executed under Matrix Reverse MUST append the standardized Negative Invariant Directive:

```text
--no text, words, letters, typography, watermark, logo, signage, characters, humans, people, faces, suits, figures, hands, mannequins, plastic glow, CGI artifacts
```

When authoring natural language prompts for systems that do not accept `--no` parameters directly, append the explicit directive:
```text
Absolutely no text, no words, no letters, no typography, no watermarks, no logos, no signs, no human beings, no people, no characters, no faces, no suits.
```
