# Reference Guide: Cinema-Grade Image & Icon Prompt Engineering (`IMG-PROMPT-01`)

## 1. Core Mandates
- **Language**: All prompts MUST be written in English.
- **Hardware Specificity**: Never use generic descriptors like "high quality" or "4K". Specify exact camera bodies, sensors, and cinema prime lenses.
- **Micro-Texture**: Always demand physical micro-imperfections, surface texture, and optical physics.

---

## 3. Standard Production Prompt Templates

### Template A: Photorealistic Cinematic Scene / Character
```text
Cinematic 8K medium close-up photograph shot on Sony Venice 2 8K Full-Frame camera with Cooke Anamorphic/i 50mm T2.3 lens, Tiffen 1/4 Black Pro-Mist filter. Dramatic Rembrandt key lighting with soft volumetric haze and warm rim backlight. Visible skin micro-textures, natural pores, subsurface scattering on ears and cheeks, and tactile fabric weave on dark wool coat. Natural 35mm Kodak Vision3 film grain, shallow depth of field with creamy oval anamorphic bokeh, deep ambient occlusion in shadows, no digital oversharpening, authentic DaVinci Resolve color grading.
```

### Template B: Modern Minimalist Logo / Icon Asset
```text
Clean modern minimalist vector logo design, Golden Ratio geometry, bold geometric silhouette with sharp clean edges, monochrome dark charcoal on subtle frosted glass background, extreme negative space symmetry, high-end Swiss typography aesthetic, optical balance, vector SVG quality, zero clutter, iconic corporate identity standard.
```

### Template C: Professional Web & UI Icon
```text
Pixel-perfect 24px UI stroke icon, crisp modern aesthetic, 1.5px consistent rounded stroke weight, optical center balanced, pure geometric lines, modern tech design system standard, translucent glassmorphism accent, isolated on transparent background, production-grade SVG vector quality.
```
